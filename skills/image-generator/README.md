# 图片生成器 image-generator

> 中文 | [English](README.en.md)

v1.0.0 · MIT License · 盘锦奇点科技有限公司

把一句话补成一段能直接用的专业生图提示词，然后按清单逐张出图。

## 特点

- **自然语言成稿**：输出是一整段连贯描述，不是关键词堆叠。景别、机位、焦距、光圈、光线方向与色温、构图、色彩配比、材质、画风串、质量词逐项落地。
- **感受词翻译**：「高级感」「氛围感」「通透」这类说不清的话，会被落到光质、色温、饱和度、构图密度这些具体参数上。
- **两种模式**：从零新建，以及基于参考图的二次生成（换装、换背景、扩画面、局部替换、转画风、精修）。
- **一致不跑偏**：角色卡 + 锚点图回传，同一张脸、同一套画风在整批图里保持一致。
- **混合画风**：支持按比例混，比如「赛博朋克 70% + CG 厚涂 30%」。只说「偏某一边」就按 10% 一档调，什么都没说就平均分。
- **画面文字可控**：书、招牌、包装、界面这类自带文字的物体就跟着出字，语种跟你的输入走；给了具体字句就逐字渲染，用双引号包住。
- **批量交付闭环**：逐张记账，单张失败不拖垮整批，重跑自动跳过已完成的。

## 用法

用自然语言说需求就行：

- `拍一张咖啡产品图`
- `给这篇文章配 5 张插图，水彩风格`
- `这个角色的 6 张表情图`
- `赛博朋克 70% + CG 厚涂 30%，18 岁狐娘少女，银发脏辫，机械猫耳`
- `把这张图改成夜景`
- `背景换成沙滩，人别动`

没指定数量默认 1 张；比例默认 1:1；画质和清晰度默认最高档。参考图给多少用多少，不设上限，参考强度默认 70%。

## 安装

本技能是**通用型** Agent Skill，不绑定任何客户端，常见 Agent 都能直接使用（Claude Code、Codex、Cursor、OpenCode、Gemini CLI、GitHub Copilot、Windsurf、Cline、Trae、Qoder 等 80 余款）。

```bash
npx skills add QYDION/ai-image-generator --skill image-generator
```

装好后在对话里直接用自然语言提需求即可，无需特殊指令。

技能本身是一个 Markdown 文件，无脚本、无外部依赖、不含机器相关路径，不与任何生图服务商绑定。生图通道由使用者自行配置。

## 兼容性

不绑定任何模型或厂商，按通道实际暴露的能力自适应：有独立的排除项字段就把排除内容写进去，没有就改成正向描述；画质有档位参数就设参数，没有就把质量词写进提示词。

默认不写 `8k`、`masterpiece` 这类评价型质量词——新一代模型默认已是最高档，写了不加分；SD 系模型仍依赖这类词，用 SD 系时自行补充。另外，入参里有 `negative_prompt` 字段不代表模型真吃，聚合平台可能只是把它归一化进来。
