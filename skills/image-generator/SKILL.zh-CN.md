# 图片生成器

> 中文 | [English](SKILL.md)

**核心职责：把用户的简单描述转成专业级生图提示词，并驱动生成。**

用户往往只给一句话或几行需求，本 skill 负责把它补全为一段可直接提交的专业 prompt，再按清单逐张生成。覆盖从零新建生成与基于参考图的二次生成（图生图）两类工作。

---

## 1. 提交原则与默认取值

### 1.1 提交原则

生成的 prompt **原样提交**，不接受任何通道的改写、润色或扩写。若所用通道存在自动改写行为，应关闭。相同主体在整套图中必须固定：同一角色的外观、脸型、肤色、发型、常服装与配饰从头至尾一致，除非用户明确要求更换服装、发型或其他特征。

### 1.2 默认取值

| 项 | 默认值 |
|---|---|
| 比例 | 用户输入优先；未指定时取 1:1，常见尺寸 `1024x1024` |
| 分辨率与画质 | 用户输入优先；未指定时取所用通道最高档 |
| 清晰度 | 默认最高清 |
| 参考强度 / 贴合度 | 用户输入优先；未指定时取 70%（分层规则见 8） |
| 参考图数量 | 不设上限，按用户提供的张数使用 |
| 混合画风比例 | 用户输入优先；说「偏 X 一些」每次调整 10%；都没说时平均分配（见 4.2） |
| 皮肤 | 按画风判定：非写实题材精修零瑕疵；写实摄影、人像摄影、纪实、电影级写实 CG 保留自然毛孔与细微油光。用户描述过的皮肤特征优先（见 6） |
| 渲染引擎 | 由画风与内容共同决定，不是必需项；多数画面不写引擎名效果更好（见 7） |
| 画面文字 | 按用户描述判定：出现自带文字的物体时随画面生成文字，语种以用户明确指定为准，未指定时才与输入语种一致；否则不生成文字、水印、Logo，需要配文案时改为留白（见下方） |

以上任一项一旦用户指定，一律按用户指定执行。

**画面文字怎么判**

先读用户的描述，判断其中出现的物体是否天然带文字：书籍、杂志、报纸、海报、招牌与门头、包装盒与标签、价签、菜单、票据、说明书、UI 界面与屏幕内容、证书、名片、横幅等。出现这类物体时，文字是该物体的固有组成部分，应随画面一起生成。

语种按下面的优先级决定：

1. **用户明确指定的文字内容优先级最高** —— 用户给了具体字句就逐字写入，不论它是否与用户提问所用的语言相同。用英文提问但要求生成中文字符，就生成中文字符；反过来也一样。用户只指定了语种、没给内容，按指定语种生成。
2. **用户没指定时，默认与用户输入的语种一致** —— 用中文描述就渲染中文，用英文描述就渲染英文。

- 用户没给内容、但物体自带文字位 → 写明该处应出现对应语种的文字，不指定具体字句，避免留白显得失真。
- 物体本身不带文字 → 不生成文字、水印、Logo，按默认写明画面干净、留白充足。

**要渲染的文字用双引号包起来**

prompt 是一整段自然语言，要出现的字和描述画面的字混在一起时，模型分不清哪部分是字面内容。把目标文字用双引号包住，等于给了它一个显式分隔符，把「要出现的字」从「对画面的描述」里切出来：

> 设计一张海报，标题是 "BLUE NOTE SESSIONS"，用粗体窄体无衬线字。

- 双引号里只放**要出现的字面内容**，任何描述都写在引号外。
- 要**改**画面里已有的文字时，用同一套引号界定前后：`把 "旧文字" 改成 "新文字"`。
- 引号内的内容**越短越准**。模型还原长句与多行排版的能力有限，超过一行就该改成留白、交给后期排版。
- 优先用英文直引号 `"`（ASCII 引号在训练语料中更常见）。

画面里的关键文字（品牌名、数字、联系方式）属高精度内容，生成后应逐项人工核对或后期重新合成，不要直接交付（见第 13 节）。

## 2. 适用边界

**非触发**：纯图像工程处理（精确抠图、去水印痕迹、批量压缩、格式转换、人脸匿名化）、视频生成、3D 模型生成。除此之外的自然语言生图与改图需求均适用。

## 3. 执行流程

### 3.1 读取素材

文本、Markdown、图片、PDF 可直接读取。其他格式若当前环境无法读取，请用户提供文本内容，**不承诺格式转换**。

长文档先抽结构（章节标题、关键结论、时间线），不将全文放入 prompt。

### 3.2 意图识别与参数补全

先确定：用途与投放位置、期望触发的行为、画面主体、整套基调。

补齐九项参数：景别、机位与视角、焦距与镜头类型、光圈、光线方案（方向 + 光质 + 色温）、构图法则、色彩与调性、材质与细节密度、文字与留白。皮肤策略、画面文字与渲染引擎在此步一并判定。信息不足时单次提问一次性确认，比例不进入提问范围。

补全依据见第 10 节；拼装为完整 prompt 的结构见 10.3。

**模糊表述的专业化**

用户给的往往是感受词，不是参数。直接把「高级感」抄进 prompt 等于没写 —— 它不指向任何可执行的成像差异。先把它落到光学、用光、色彩、构图这些能落地的地方，再进入拼装。

| 用户说的 | 落到 prompt 的具体项 |
|---|---|
| 高级感 / 有质感 | 低饱和中低对比，侧光或侧逆光塑形，材质写具体（釉面颗粒 / 拉丝金属 / 霜面玻璃），后期克制 |
| 氛围感 | 写明光质与色温（如 3200K 暖调低照度），加一层环境介质（薄雾 / 浮尘 / 水汽），压暗背景 |
| 电影感 / 大片感 | 宽幅 2.39:1，变形宽银幕，强轮廓光，高动态范围但后期克制，低机位或过肩 |
| 干净 / 极简 | 大面积负空间，单一主色，无杂物件，柔光箱正面光消除杂乱阴影 |
| ins 风 | 高亮度低饱和，自然光，留白大，主体占画面 ≤ 1/3，轻胶片颗粒 |
| 治愈系 | 高明度暖调，柔光，圆角与软材质，浅景深，无强对比 |
| 复古 | 低饱和偏黄绿，胶片颗粒与轻微漏光，柔焦，老镜头的旋转焦外 |
| 科技感 | 冷色温，硬光或边缘光，金属与玻璃材质，深色背景配干净高光 |
| 温暖 | 色温 3200–4000K，暖色主色，柔光，暗部保留细节 |
| 清凉 | 色温 5500K 以上偏冷，青蓝色系，高调布光，高光干净 |
| 通透 | 逆光或侧逆光，空气介质干净，低对比高亮度，高光不过曝 |
| 厚重 | 低调布光，暗部占比大，高对比，深色材质与粗糙质感 |
| 有烟火气 | 现场光，轻微手持感，生活杂物入画，暖色温，不完美的构图 |
| 商业感 / 电商 | 纯净背景，柔光箱配两侧吸光板，材质真实，边缘干净，主体 ≥70% |
| 杂志感 / 编辑感 | 强概念构图，留白与标题位，单一光源方向，色彩高度统一 |
| 少女感 | 高明度粉调，柔光与轻微过曝，圆润造型，低对比 |
| 手作感 | 可见的手工痕迹（纸纹 / 笔触 / 毛边），自然光，暖白平衡 |
| 硬核 | 高对比，单一硬光，冷或中性色温，工业材质，低角度 |

一个感受词通常要同时落到 3–4 个维度（光质、色温、饱和度、构图密度），不是一词换一词。用户给的是同义叠词（「高级又干净」）时取交集，不并列堆砌。

### 3.3 方案表

直接输出表格并执行，**不阻塞等待确认**：`# / 来源或用途 / 画面描述 / 景别 / 焦距与光圈 / 光线 / 参考强度 / 备注（是否留文案位）`。

数量以用户输入为准；用户未指定时默认 **1 张**，不追问。

### 3.4 生成与交付

生成前建立任务清单，逐张执行并回写状态：

| # | 画面描述 | 参考强度 | 状态 | 输出 |
|---|---|---|---|---|
| 1 | … | 70% | 待生成 / 已生成 / 失败 | 实际文件路径 |

- 逐张调用。每张完成后立即记录**实际输出路径**与状态，不重命名文件
- 单张失败**不中断整批**：记录序号与原因，继续下一张
- **续跑**：同一任务重跑时，先读清单与输出目录，已成功的跳过，不重复消耗额度
- 中途不变更画风与比例；单张不满意只重生成该张
- 全部结束后报告：**共 N 张，完成 X 张，失败 Y 张**。失败项逐条列出序号与原因；部分完成时如实说明部分完成
- 任务受理、进度或中间状态都不等于已完成

交付时按清单顺序一次性呈现全部图片，说明所用比例、画质、张数、输出路径与后续用法，并核对落盘数量与清单一致，按第 12 节排查常见问题。

## 4. 画风系统

### 4.1 单画风锁定

整套图共用同一串画风描述，包含艺术媒介、笔触或渲染方式、色彩策略、光影逻辑、后期质感。确定后不得更改。

示例：`整体为 3D 卡通渲染，造型圆润，全局光照柔和，材质呈橡胶般的质感，色调为明亮的奶油色，带轻微景深，数字后期干净无噪点。`

### 4.2 混合画风

画风混合的写法不限，以下都有效：

- 带加号：`赛博朋克 70% + CG 动画 30%`
- 不带加号：`赛博朋克和 CG 动画混合，偏赛博朋克`
- 只并列名称：`水彩 + 国风水墨`

**优先引导用户直接给比例**，例如「A 七成 B 三成」。用户给出比例时严格照其比例写入 prompt。

用户没给比例时，按主次表述判定：

| 用户表述 | 比例 |
|---|---|
| 「偏 X 一些」 | 以均分为基准，X 上调 10 个百分点 |
| 「再偏一些」「更偏 X」 | 在上一次结果上再上调 10 个百分点 |
| 未表达主次 | 平均分配：2 种各 50%，3 种各 33.3% |

每次「偏 X 一些」的调整量固定为 10%：两种画风从各 50% 起步，说一次得到 60% / 40%，再说一次 70% / 30%，依此类推；三种画风从各 33.3% 起步按同一幅度调整。「各一半」「五五开」算平均分配，但需说明占比相当时两种画风的特征容易互相稀释。

比例结果需在交付时说明。

融合写法（占比按上表代入，下例为 70/30）：

> `整体以 A 为主（70%），B 作为次要影响（30%）融入 <维度：背景笔触 / 材质表现 / 边缘描边 / 色彩倾向>；两者融合自然，光照方向、线条粗细、色彩饱和度统一。`

平均分配时改写为：

> `A 与 B 等量融合，各自贡献 <维度分工>；光照方向、线条粗细、色彩饱和度统一，避免特征互相稀释。`

强冲突组合（写实照片 × 扁平矢量）改为载体分工：主体走 A、背景走 B，或材质走 A、轮廓走 B；也可先按 A 生成，再以 B 风格做图生图转换。

整套图要求：混合占比、光源方向、色温、焦距一致。

### 4.3 常用画风词

**现代生图主力**：写实摄影｜电影级 CG｜3D 卡通渲染｜皮克斯风格｜日系赛璐璐｜扁平矢量｜国风水墨｜赛博朋克霓虹｜像素 art｜Low-poly｜吉卜力｜美漫 / 日漫｜黑白胶片

**传统媒介，需补充笔触或纸张细节才有好效果**：厚涂油画｜水彩手绘｜素描线稿｜Retro 波普

## 5. 角色一致性

### 5.1 角色卡

**固定项**：性别年龄段、脸型五官、肤色、发型发色长度、体型、常服装（**上装 + 下装 + 鞋，逐件写明款式、材质、配色**）、标志性配饰、妆容强度、皮肤处理方式。

下装与鞋必须写。实测只写上装时，模型会自行补下装，且每张补得不一样 —— 同一角色的裤装与鞋在序列里会反复变。

**可变项**：表情（分解为眉、眼、口的具体变化）、肢体动作与手势、机位景别、场景、光线方向。

执行要点：

1. 先生成一张半身标准像作为锚点。
2. 后续每张传入锚点图作为参考输入，参考强度取默认 70%；过高会锁死表情，过低会导致面部漂移。
3. 多角色场景为每人指定代号，全程使用代号指代。
4. 同一人物年龄演化保留标志性特征，仅改与年龄相关的部分。
5. 图生图继承参考图景别。需改变景别时，在 prompt 中以硬约束描述（占画面比例、边缘裁切位置），或以目标景别生成锚点；仍无法改变则按原景别交付并说明可裁剪。裁剪不产生额度消耗，重生成会产生。
6. 系列图相邻两张之间只变更一个变量，光源方向与焦距整套不变，避免主体在序列中跳动。

## 6. 皮肤策略

由画风与用途决定，用户描述过的皮肤特征优先级最高。

| 条件 | 模式 | 说明 |
|---|---|---|
| CG 动画 / 二次元 / 卡通渲染 / 平涂插画 / 产品商业 / 美妆 / 时尚 / 社媒 | 精修 | 瓷感光滑、肤色均匀明亮、底妆精修的成品妆效 |
| 写实摄影 / 人像摄影 / 纪实 / 电影级写实 CG / 偏真实感的三维渲染 | 写实保留 | 保留自然毛孔与细微油光，肤色干净，瑕疵轻微 |
| 科幻 / 赛博朋克 / 半写实 CG / 带真实光学的插画（浅景深、真实镜头） | 写实保留 | 题材虚构不等于皮肤要磨平。只要画面要求真实材质与真实光学，就走写实保留 |
| 混合画风 | 按占比较高的一端 | 例：CG 动画 70% + 赛博朋克 30% 取精修 |
| 用户明确描述皮肤特征 | 按用户描述 | 写入角色卡，整套一致 |

实测提醒：赛博朋克、半写实角色若误走精修，皮肤会呈塑料感，同时把皮革与织物的真实纹理一并磨平。这类题材优先取写实保留。

**精修模式串**

> 皮肤：瓷感光滑通透，肤色均匀明亮，水润饱满，商业美妆级精修质感，柔和细腻的高光过渡，清洁净透的妆效。
> `flawless porcelain-smooth skin, even luminous complexion, high-end beauty retouching, soft natural shading, naturally refined`

**写实模式串**

> 皮肤：真实的人像肌肤质感，保留自然的毛孔与鼻翼、额头的细微油光，干净的肤色，瑕疵轻微且分布自然，保留柔和的明暗过渡。
> `natural skin texture with fine pores, subtle natural oil sheen, healthy even skin tone, light retouching, realistic portrait skin`

两种模式下，睫毛、唇纹、发丝都不做过度平滑。

### 6.1 不要用否定词列举具象瑕疵

写「无雀斑、无痘印、无可见毛孔」会把这三个概念带进 prompt，实测反而更容易把雀斑画出来 —— 文本编码器对否定的处理能力很弱。一律改用正向描述（瓷感光滑、肤色均匀明亮、底妆精修），并避免提及任何瑕疵名称。通道提供独立排除项字段时，这几项写进该字段更有效；本节的正向写法用于通道没有该字段时（见 11.1）。

同一原则适用于画面元素：物体本身不带文字、需要避免画面出现文字、水印、Logo 时，优先写正向的「画面干净、留白充足」，而不是「不要文字」这样的否定指令（物体天然带文字时按 1.2 处理，不适用本条）。

否定抽象质感形容词（如「不够柔和」一类）的影响小于否定具象名词，但效力同样有限，不作为默认手段。

### 6.2 正向描述压不住时

改用二次精修定向修正（见 10.4）：以该图作为参考输入、参考强度取高值（80% 以上），prompt 只写皮肤增量（统一肤色、加强磨皮、妆面均匀服帖），其余写明保持不变。实测对「模型先验倾向年轻女性带雀斑」这类顽固特征有效。

## 7. 渲染引擎与物理仿真

### 7.1 是否需要写入

引擎与解算器由**画风与内容共同决定**，不是必需项。写实、写实向 CG、三维渲染类题材可写；2D、插画、扁平、像素、线稿不写，否则画面会偏向写实。

**多数画面不写引擎名效果更好。** 只有当画面明确依赖某种渲染质感（皮肤次表面散射、金属焦散、光线追踪反射、体积介质）时才写。每张图只指定一个引擎，不叠加。

### 7.2 常用引擎

| 引擎 | 特点 | 适用 |
|---|---|---|
| Arnold | 皮肤次表面散射、毛发、布料表现成熟 | 电影级角色、写实人物 |
| RenderMan（RIS） | 影视制式，毛发与体积渲染 | 高规格 CG 镜头、动画电影 |
| V-Ray | 通用性强，材质库大 | 建筑、产品、影视通用 |
| Corona | 出图快，光线柔和自然 | 建筑室内、产品静物 |
| Cycles | 开源离线，功能完整 | CG 短片、概念场景 |
| Redshift | GPU 影视级，支持 SSS 与毛发 | 角色、产品、广告 |
| Octane | GPU 光谱渲染，金属与玻璃高光干净 | 产品、工业件、美妆 |
| Unreal Engine 5 | Lumen 全局光、Nanite、Path Tracer | 游戏感画面、虚拟场景 |
| Keyshot | 工业级材质与配色表现 | 产品设计、材质评审 |
| Houdini Karma | 粒子、流体、烟火、体积介质 | 特效镜头 |
| Blender EEVEE + 卡通着色 / UE5 NPR | 描边与分层着色可控 | 日系动画、三渲二 |

三渲二题材通常不必写引擎名，改写 `NPR 卡通渲染、赛璐璐分层着色、清晰描边、平涂高光` 更有效。

### 7.3 题材对照

| 题材 | 首选 | 备选 |
|---|---|---|
| 产品、工业件、电商主图 | Octane、Keyshot | V-Ray、Corona |
| 影视级角色（皮肤、毛发、布料） | Arnold、Redshift | RenderMan、V-Ray |
| 室内、建筑、空间 | Corona、V-Ray | — |
| 实时质感、游戏感、虚拟场景 | Unreal Engine 5 | — |
| CG 短片、概念场景 | Blender Cycles | Arnold、Redshift |
| 大场面、粒子、流体 | Houdini Karma | — |
| 动漫、赛璐璐 | Blender EEVEE + 卡通着色 | UE5 + NPR |

### 7.4 配套光学与着色术语

全局光照 GI、HDRI 环境光、次表面散射 SSS（皮肤、蜡烛、玉石、乳制品必开）、环境光遮蔽 AO、光线追踪反射与折射、焦散 caustics（玻璃、水、金属）、体积介质与体积雾、景深 DOF、采样去噪、路径追踪 path tracing、微置换 micro-poly displacement、ACES 色调映射。

这些术语对成像的实际引导力高于引擎软件名，需要控制画面质感时优先使用它们。

### 7.5 物理仿真与解算

画面里存在布料、毛发、液体、烟雾、破碎、粒子群集时，形态是否合理取决于动力学解算。此类题材需同时写明两件事：**用哪个解算器**，以及**解算后的形态特征**。仅写软件名效力有限，形态描述更重要。

| 模拟对象 | 常用解算器 | 形态描述词 |
|---|---|---|
| 服装、布料、垂坠 | Marvelous Designer、CLO 3D、Houdini Vellum、Maya nCloth、Blender 布料 | `natural drape, realistic fold structure, fabric tension at stress points, soft irregular folds` |
| 毛发、groom | XGen、Ornatrix、Yeti、Houdini 毛发 | `natural gravity fall, individual strand detail, subtle frizz, layered groom` |
| 液体、飞溅 | RealFlow、Houdini FLIP、Phoenix FD、Blender Mantaflow、LiquiGen | `surface tension, droplet breakup, thin sheet and ribbon forms, splash crown` |
| 火焰、烟雾、爆炸 | Phoenix FD、Houdini Pyro、FumeFX、EmberGen | `volumetric smoke with wispy detail, self-shadowing, buoyancy-driven plumes` |
| 刚体、破碎、软体 | Houdini RBD、Bullet、PhysX / NVIDIA Flex、Blender MPM | `Voronoi fracture pattern, secondary debris, plausible mass and stacking` |
| 粒子、群集 | Houdini POP、X-Particles、nParticles | `non-uniform distribution, size variation, clumping, motion trails` |
| 植被、生态 | SpeedTree | `species-accurate branching, wind response, seasonal variation` |
| 人群、交通 | Massive、Golaem | `varied gait and spacing, individually distinct silhouettes` |

使用边界：静态图中不必逐项写入，仅当画面**明显依赖**某种动力学形态时才提（飘动的衣摆、飞溅的液体、垂坠的头发、烟雾爆炸、破碎瞬间）。整套图需保持同一套动力学假设，例如同一阵风方向下的发丝与衣摆朝向必须一致。

常见组合：Houdini 解算 + Redshift / Arnold / Karma 渲染；Marvelous Designer 出服装版型 → 导出 → Keyshot / Octane 渲染。

### 7.6 一致性与边界

整套图使用同一引擎、同一色调映射、同一 GI 设置，避免材质反射在张与张之间不一致。用户指定引擎时按其指定执行。

写入引擎名是对成像风格的引导，**不代表实际调用该管线，不得向用户作此承诺**。

## 8. 基于参考图的二次生成

| 任务 | 参考强度 | 处理方式 |
|---|---|---|
| 整体改写重绘 | 40–50% | 传入原图，prompt 写目标效果；需较大改动时降低参考强度 |
| 换服装、发型、配色 | 70% | prompt 只写变更项，其余写明保持不变 |
| 替换背景 | 70% | 有旧图时走图生图只改背景，无旧图时从零生成（见下方） |
| 画面扩展 | 75–85% | 沿用原图机位、焦距、光源方向与色温，描述延伸方向的内容；原图边缘可能出现透视差异，需提前说明 |
| 局部对象替换 | 70% | 说明替换对象与保留区域，复杂改动分步进行 |
| 风格迁移 | 40–50% | 传入原图，描述目标画风与占比，必要时多轮微调 |
| 清晰度精修 | 75–85% | 见 10.4 |
| 角色一致性锚点回传 | 70% | 见 5.1 |

**环境与背景的定向修改（如「背景换成夜晚」）**

判断依据是「旧图是否已达到可复用标准」，而不是「有没有旧图」：

- **有可用的旧图** → 以该图为参考输入做图生图，参考强度 70%，prompt 只写背景增量（改为夜晚、夜景光源、色温与氛围），主体、机位、构图写明保持不变。
- **没有旧图**（用户只给了描述）→ 按新需求从零生成，把白天与夜晚的差异完整写进 prompt。
- **有旧图但主体或构图本身不满意** → 不用旧图做参考，按目标从零生成，避免把不满意的部分一并锁死。

环境变更（昼夜、天气、季节、场景替换）同此规则。

**参考强度与贴合度是同一个概念在不同通道里的不同叫法**，统一按一个值处理。

落到通道时按三级映射：通道支持连续数值 → 传对应数值；通道只支持档位 → 70% 就近映射到高档；通道没有该参数 → 在 prompt 中写明保留程度。

prompt 中明确写出「保持不变的部分」与「需要变更的部分」。

## 10. 镜头与光学参数

### 10.1 焦距与镜头类型

**焦距**：14–24mm 超广角（空间张力、建筑）｜35mm（叙事、环境人像、纪实）｜50mm（标准视角，产品与日常）｜70–85mm（人像主力）｜100–135mm（肖像特写、美食、珠宝）｜90–105mm 微距（材质纹理）｜200mm 以上远摄（空间压缩、偷窥视角）。

**镜头类型**，每张图指定一种，不叠加：

| 类型 | 视觉特征 | 适用 |
|---|---|---|
| 人像定焦（85mm 级，f/1.2–1.4） | 面部透视讨好，焦外奶油化 | 人像特写、专家形象 |
| 标准定焦（50mm 级） | 接近人眼，微反差高，边缘锐利 | 产品、日常场景、需要真实感 |
| 微距（90–105mm，1:1 以上） | 纹理极度清晰 | 食材、珠宝、织物、元件、印刷细节 |
| 探针 / 特种 | 广角虫视，近摄仍有大景深，可入窄缝 | 工业检测、美食穿行镜头、产品内部 |
| 移轴 | 透视校正，垂直线不倒，合焦面可倾斜 | 建筑、室内、商品、菜品（可做微缩景深） |
| 电影镜头 | 呼吸效应校正，焦外圆润，灰阶厚 | 影视级画面、叙事类 CG |
| 变形宽银幕 | 椭圆边缘光斑、横向蓝拉丝、2× 压缩宽幅 | 电影感海报、赛博朋克视觉 |
| 中画幅 | 极高细节，肤色细腻，景深浅 | 高端商业、时尚、大幅面输出 |
| 远摄（200mm 以上） | 空间压缩，背景化为色块 | 体育、野生动物、城市远景、悬念感 |
| 航拍 / 运动相机 | 固定光圈大景深，第一人称运动感，桶形畸变与强防抖 | 航拍俯瞰、极限运动、POV 视角、地产鸟瞰 |
| 鱼眼 | 接近或超过 180°，极端边界变形 | 滑板、极限运动、装置视角、视觉冲击 KV |
| 复古老镜 | 旋转焦外、边缘发散、柔焦怀旧 | 复古题材、氛围向人像 |
| 手机主摄 | 等效 24–28mm，轻压缩，真实随手感 | UGC、社媒真实感、生活化内容 |

品牌与具体型号对成像的引导力远低于焦距与光圈数值，不作为必填项。

### 10.2 光圈、视角、光线、构图、色彩、质感

**光圈**：f/1.2–1.8 突出主体，整套建议不超过一张｜f/2.8–4 通用｜f/5.6–8 产品与合影整体清晰｜f/8–11 建筑、室内、大景深。整套至少包含一张 f/8 全景用于交代环境。

**视角**：眼平（默认，人物交流）｜低角度（权威、压迫）｜正俯（秩序、清单）｜45° 斜俯（立体与信息兼顾，常用）｜过肩（代入叙事）｜荷兰角（不安感，慎用）。避免连续三张同视角。

**光线**：默认三点布光（主光塑形、补光避免暗部糊成一团、轮廓光分离主体与背景）。可选柔光箱、45° 侧上光、伦勃朗光、蝴蝶光、分割光、轮廓光 / 逆光、窗光、金色时刻、蓝调时刻、低调布光配单一硬光。每项写明光源方向、光质软硬、色温。

**构图**：三分法（默认）｜中心对称｜引导线｜框架构图｜负空间（需放文案时使用）｜黄金分割｜knolling 秩序排列。

**色彩**：先定色温，再定饱和度与对比。低饱和中低对比偏克制，高饱和高对比偏活力。主色 60%、辅色 30%、点缀 10%，整套一致。避免冷暖混搭、多主色并存、青橙调过度。

**质感**：Kodak Portra（柔和暖调）｜Velvia（高饱和风光）｜CineStill（夜景暖光晕）｜黑白胶片（强调结构）｜干净数字无颗粒（商务、电商、科技默认）。后期写 `natural dynamic range, restrained post-processing`，不使用 HDR 类描述。

### 10.3 Prompt 结构

**用自然语言写成一段连贯的描述。** 不要用 `[标签] + [标签]` 的堆叠写法，也不要把要素拆成逗号分隔的关键词表。当前主流生图模型按句子理解语义，成段的叙述能表达出要素之间的关系 —— 谁在做什么、光从哪来、主体与背景如何分离 —— 而分立的标签只能各自表态，无法交代关系。

一段完整的 prompt 按下面的顺序自然展开，各项融进句子里，不必逐项打标签：

1. **主体与特征** —— 是谁 / 是什么，外貌、材质、颜色、状态。
2. **动作或状态** —— 主体正在做什么，或处于什么状态。
3. **环境** —— 由近及远交代：前景有什么、主体所在层面、背景是什么。
4. **画风** —— 媒介、笔触或渲染方式、色彩策略、光影逻辑、后期质感；混合时写明占比。
5. **渲染与物理**（按 7.1 判断是否需要）—— 只在画面明确依赖某种渲染质感时才写。
6. **角色卡**（含皮肤策略，见第 6 节）—— 有人物时把固定特征与可变项写进同一段。
7. **镜头** —— 机位、焦距、镜头类型、光圈。
8. **光线** —— 光源方向、光质软硬、色温。
9. **构图与配色** —— 构图法则、留白位置、主辅点缀色配比、质感与后期。
10. **材质与细节密度**，末尾接**质量词**（见 10.4）与**约束**（画面干净、留白充足、地平线水平）。用户自己写了质量词时例外，前置到开头（见 10.4）。

写成一句或几句连贯的话即可，自然衔接。信息不足时按最小充分原则补足，不为了「写全」而堆砌同义描述。

示例（原始需求「配一张咖啡产品图」）：

> 一杯刚冲好的手冲咖啡盛在哑光陶瓷杯里，杯口正自然升腾着细微蒸汽，浅橡木桌面上散落着几颗咖啡豆和一张滤纸作为前景纵深，背景是一面虚化的暖色木墙。整体是干净细腻的商业写实摄影，低饱和暖调，主色为陶土棕、以深褐点缀，影调干净、后期克制无颗粒。机位 45° 斜俯，用 90mm 移轴镜头、f/5.6 拍摄。左上方柔光箱作侧逆光，勾出杯口蒸汽的轮廓，右侧反光板补光压住暗部，色温约 3800K 偏暖。三分法构图，右上角留出充足空白以便后期放置文案。陶土杯身保留细微的釉面颗粒与拉坯纹理，液面有干净的高光反射。`sharp focus, fine detail, high micro-contrast, crisp clean edges, professional retouching, natural texture`。画面干净，留白充足，地平线水平。

反例：`咖啡，好喝的样子，高级感，8k，超清，大师作品`。既不含可执行信息，也没有任何要素关系。

### 10.4 清晰度、质量与二次精修

画质参数取用户指定值，未指定时取所用通道最高档。清晰度默认最高清。

**质量提示词**置于 prompt 尾部：

> `sharp focus, fine detail, high micro-contrast, crisp clean edges, professional retouching, natural texture`

不使用 `8k, ultra HD, masterpiece, trending, best quality`，常见结果是过度锐化与塑料质感。

两者的区别不是「要不要质量词」，而是**描述客观属性还是索要质量等级**：上面那串说的是合焦、细节密度、边缘是否干净、材质是否真实，任何代际的模型都成立；被禁的那类是向模型要一个「质量档位」，而新一代模型默认已是最高档，写上去不涨质量，只涨过度锐化与塑料感。质量词在 SD 系工作流上仍是必需的，在新一代模型上属无害冗余，因此保留。

用户自己在需求里写了质量词（`8k`、`大师作品`、`超清` 之类）时，按用户输入优先处理：保留原词，不做替换，并**前置到 prompt 最开头** —— 位置越靠前权重越高，前置才能确保它生效。上面的禁用规则只约束本技能主动追加的内容，不约束用户指定的词。

有人物的图按第 6 节判定皮肤模式，不用泛用 `natural texture` 决定肤质。精修模式补充 `high-end beauty retouching, skin smoothing, even skin tone, subtle glow`。

**二次精修**：传入上一版作为参考图，参考强度取 75–85% 保持构图，prompt 只写增量（提升材质清晰度、清理边缘毛刺、降低噪点、统一色温；皮肤方向按所处模式）。该步骤产生额外额度消耗，需提前说明。

## 11. 调用规范

### 11.1 参数合法性

调用前核对实际返回的入参说明，尤其是 `size` 取值范围、`quality` 档位，以及是否存在独立的排除项字段。`1024x1024` 与 `high` 为常见值而非保证值。

不得传入通道不支持的参数。排除项按通道实际能力分两条路：通道提供独立的排除项字段，把排除内容写入该字段；通道没有该字段，写成陈述句或正向描述置入 prompt，不用否定指令（原理见 6.1）。字段存在不等于会生效 —— 聚合平台常把各模型归一化成同一套入参（`prompt` / `negative_prompt` / `steps` / `guidance`），无关字段可能被静默忽略；写入后未生效则回退正向描述，不反复重试。

prompt 原样提交，不接受通道改写（见 1.1）。

### 11.2 比例映射

| 用户说法 | 取向 | 说明 |
|---|---|---|
| 未指定 / 方图 / 1:1 | 方构图 | `1024x1024` |
| 横版、封面、PPT 用图、16:9 | 最大横构尺寸 | 常见 `1536x1024`（3:2），非原生 16:9，需说明 |
| 竖版、手机海报、9:16 | 最大竖构尺寸 | 常见 `1024x1536`（2:3），非原生 9:16，需说明 |
| 4:5、21:9 等 | 最接近的支持尺寸 | 说明已退化并提供裁剪选项 |

用户输入的比例权重最高。不支持的比例不得静默替换，两条路径：用最接近比例出图，或先出图后裁剪。裁剪不产生额外额度消耗。

### 11.3 输出

输出至工作区下 `generated-images/<任务名>/`，任务名用简短 slug。文件名由生图通道生成，不做重命名。序列类图片保持顺序清晰。交付时按清单顺序一次性呈现全部图片。

### 11.4 额度

批量生图前说明张数与预估消耗，**不阻塞执行**。续跑时跳过已成功的张数，不重复消耗。

## 12. 常见问题与预防

| 问题 | 预防 |
|---|---|
| 加了否定词反而出现该瑕疵 | 否定具象名词会把概念带进画面。改成正向描述，或直接走二次精修 |
| 排除项写进字段后无效果 | 该字段可能是聚合平台归一化出来的空壳。回退为正向描述，不反复重试 |
| 取景被参考图拖成胸像 | 锚点图直接用目标景别生成，不要先出半身再指望后续收紧 |
| 手部畸形 | 手部不置于显眼位置，必要时持物或位于边缘，写入 `natural anatomy` |
| 精修题材出现雀斑与粗糙质感 | 挂载第 6 节正向皮肤串，不写任何否定词；仍不奏效则走 10.4 二次精修定向修正 |
| 画面出现乱码文字 | 物体不带文字时写明画面干净、留白充足；带文字时按 1.2 判定语种与内容，关键文字生成后人工核对或后期合成 |
| 地平线与建筑竖线歪斜 | 写入 `level horizon, vertical lines corrected` |
| 过度处理 | 写入 `natural dynamic range, restrained post-processing` |
| 同一角色跨图不一致 | 角色卡 + 锚点图 + 图生图回传，参考强度 70% |
| 画风漂移 | 画风串整套不变，混合画风整套同占比；确认 prompt 未被通道改写 |
| 序列图中主体跳动 | 相邻张只变更一个变量，光位与焦距整套不变 |
| 写实题材被过度平滑 | 使用第 6 节写实串 |
| 图生图偏离参考过远 | 提高参考强度，prompt 中列出需保持不变的部分 |
| 单张生成失败导致整批中断 | 失败项单独记录并继续，结束时按部分完成报告 |

## 13. 交付检查

落盘数量与任务清单一致；比例与约定一致且不支持的比例已提前说明；画质取用户指定值或通道最高档；画风串整套一致且混合占比已复述；人物跨图一致；无乱码文字与畸形肢体（按 1.2 生成的文字已人工核对）；序列顺序正确；prompt 未被通道改写。
